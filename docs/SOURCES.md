# ConsumerShield — Data Sources

This document records the sources used or planned for the ConsumerShield legal-information dataset. Source availability does not automatically grant permission to reproduce or redistribute the full content.

## 1. Source record format

Each source record should contain:

| Field | Description |
|---|---|
| ID | Unique dataset identifier |
| Title | Official document or source name |
| Publisher | Government department, commission, or authority |
| Source URL | Original official webpage or document |
| Source type | Act, rule, guideline, FAQ, portal, or judgment |
| Publication date | Official publication date, where available |
| Access date | Date the source was retrieved |
| Licence / terms | Applicable reuse and attribution conditions |
| Verification | Whether the exact document and URL have been checked |

## 4. Source usage and terms

1. Prefer original government and commission websites over third-party summaries.
2. Preserve the original source URL and identify the issuing authority.
3. Record publication dates and access dates whenever available.
4. Public availability must not be treated as an open licence.
5. Check the source website's applicable terms, copyright notice, and reuse policy before reproducing or redistributing documents.
6. Attribute the issuing authority and link to the original document.
7. Store only the material necessary for search, retrieval, and evidence-backed answers, subject to applicable permissions.
8. Do not remove copyright notices or imply that ConsumerShield owns government publications.
9. Do not invent missing case details, dates, citations, or legal outcomes.
10. When a source cannot be verified, mark it as unverified and do not use it as authoritative evidence in an answer.

## 5. Verification and maintenance

For each source, maintain:

- Exact document title.
- Original publisher.
- Working document-level URL where available.
- Publication or amendment date.
- Access date.
- Reuse and attribution terms.
- Verification status.

Review broken links and updated legislation periodically. Where a law has been amended, distinguish the original text from the current consolidated or amended version.
